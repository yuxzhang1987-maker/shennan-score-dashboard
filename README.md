# 深南电路智能监控评分看板

## 本次升级内容
- 五项评分，权重合计100%：深南电路自身走势25%、PCB板块20%、大资金流20%、美股科技趋势15%、基本面/AI资本开支人工代理20%。
- GitHub Actions 工作日北京时间约09:05至15:05每小时运行一次。
- 每次运行保存一条 `data/hourly_history.csv`，每日汇总/最新快照继续写入 `data/history.csv`，原有日度历史保留。
- 达到60、70、80、90分阈值时可通过 PushPlus 微信推送；回落到60分以下后重新解锁提醒。
- 数据源失败时不伪造数据；缺失指标不计入有效权重，并显示数据覆盖率和错误信息。

## 数据来源与口径
- 深南电路日线、60分钟线：AkShare 调用东方财富接口。
- 主力资金流：AkShare 调用东方财富个股资金流接口。
- PCB：优先尝试东方财富PCB概念历史数据；不可用时使用“元件”行业作为代理，并在数据源字段中注明。
- 美股科技：AkShare 新浪财经纳斯达克100指数数据。海外市场休市时，数据日期不会变化；页面会显示其数据日期。
- 基本面：目前仍是人工AI资本开支/基本面代理信号，不是自动财报分析。`data/ai_signal.txt` 范围-2至+2，默认中性0，对应50分。

## 微信推送配置
1. 登录 PushPlus，获取自己的 Token。
2. 打开 GitHub 仓库 → Settings → Secrets and variables → Actions。
3. 点击 New repository secret。
4. Name 填 `PUSHPLUS_TOKEN`，Secret 填自己的 Token。
5. 保存。不要把 Token 写入代码、README 或公开文件。

未配置 Token 时评分和历史记录仍可运行，但不会推送微信提醒。

## 部署
Streamlit Community Cloud 继续选择原仓库、`main` 分支、`app.py` 主文件。更新代码后原部署通常会自动重新部署。

## 注意事项
- GitHub Actions 定时任务可能延迟，也可能因数据网站限流或接口变更而失败。
- 小时更新以东方财富60分钟K线为主；不是逐笔实时行情。分钟线可能在当前小时内尚未收盘。
- PCB历史接口若不可用会尝试“元件”行业代理，页面/记录会标注代理来源。
- 当前基本面项是人工代理信号，不应误读为自动财报评分。
- 资金流是数据平台按成交单分类估算，不等于真实机构账户；不同平台口径可能不同。
- 本模型尚未完成历史回测，不代表上涨概率，不构成投资建议或自动买卖信号。
