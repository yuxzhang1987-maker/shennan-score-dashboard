# 深南电路智能监控评分看板

## 本次升级内容
- 五项评分，权重合计100%：深南电路自身走势25%、PCB板块20%、大资金流20%、美股科技趋势15%、基本面/AI资本开支人工代理20%。
- GitHub Actions 工作日北京时间约09:05至15:05每小时运行一次。
- 每次运行保存一条 `data/hourly_history.csv`，每日汇总/最新快照继续写入 `data/history.csv`，原有日度历史保留。
- 达到60、70、80、90分阈值时自动在网站内记录提醒；回落到60分以下后重新解锁下一轮提醒。无需 Token。
- 数据源失败时不伪造数据；缺失指标不计入有效权重，并显示数据覆盖率和错误信息。

## 数据来源与口径
- 深南电路日线、60分钟线：AkShare 调用东方财富接口。
- 主力资金流：AkShare 调用东方财富个股资金流接口。
- PCB：优先尝试东方财富PCB概念历史数据；不可用时使用“元件”行业作为代理，并在数据源字段中注明。
- 美股科技：AkShare 新浪财经纳斯达克100指数数据。海外市场休市时，数据日期不会变化；页面会显示其数据日期。
- 基本面：目前仍是人工AI资本开支/基本面代理信号，不是自动财报分析。`data/ai_signal.txt` 范围-2至+2，默认中性0，对应50分。

## 阈值提醒（无需 Token）
- 不需要注册 PushPlus，不需要申请 Token，也不需要在 GitHub Secrets 中配置任何提醒密钥。
- 综合评分首次达到60、70、80、90分时，系统会将触发时间、阈值、当时评分写入 `data/alert_history.csv`。
- 评分回落到60分以下后，会解锁下一轮阈值提醒。
- 提醒记录显示在网站的“评分阈值提醒记录”区域，也可以下载 CSV。
- 当前版本是网站内提醒记录，不会主动发送微信消息或手机通知。

## 部署
Streamlit Community Cloud 继续选择原仓库、`main` 分支、`app.py` 主文件。更新代码后原部署通常会自动重新部署。

## 注意事项
- GitHub Actions 定时任务可能延迟，也可能因数据网站限流或接口变更而失败。
- 小时更新以东方财富60分钟K线为主；不是逐笔实时行情。分钟线可能在当前小时内尚未收盘。
- PCB历史接口若不可用会尝试“元件”行业代理，页面/记录会标注代理来源。
- 当前基本面项是人工代理信号，不应误读为自动财报评分。
- 资金流是数据平台按成交单分类估算，不等于真实机构账户；不同平台口径可能不同。
- 本模型尚未完成历史回测，不代表上涨概率，不构成投资建议或自动买卖信号。

## 2026-11 数据源可靠性升级说明

本版本针对“深南电路自身走势、PCB板块走势取数失败”增加了中国境内公开行情源的多级回退：

- **深南电路日线**：东方财富公开K线接口优先；失败时依次切换新浪财经、腾讯财经；AKShare作为额外兜底（若安装）。
- **深南电路60分钟线**：东方财富优先，新浪财经备用。分钟线失败时仍使用有效日线计算个股评分，不再因此丢失整个个股指标。
- **PCB板块**：优先从东方财富概念板块列表动态识别“PCB概念”代码并获取板块K线；若板块指数接口失败，则使用多只PCB相关上市公司日线构建等权代理指数（腾讯/新浪行情）。该代理会在数据源栏明确标注，不冒充官方板块指数。
- **数据质量**：日线要求至少55条有效记录，并检查最新交易日期；过旧数据拒绝进入当次评分。每次记录单独写入深南与PCB数据源、PCB数据日期和异常原因。
- **覆盖率**：未录入 `data/ai_signal.txt` 时，基本面50分只作为页面占位显示，不再伪装成有效采集数据，也不计入覆盖率和综合评分权重。

### 重要限制

上述均为中国网站公开、非官方行情接口，可能出现限流、字段调整或访问策略变化。GitHub Actions 的云端运行环境不等于中国大陆网络环境，某些接口仍可能被限流。程序会自动切换备用源并记录实际来源；若所有源均失败，会显示异常，不会用旧行情冒充最新行情。部署后请以页面中的“行情数据时间”“深南电路数据源”“PCB板块数据源”和 GitHub Actions 日志为准。


## PCB 数据策略（A方案）

1. 优先读取东方财富 PCB 概念板块官方行情（优先尝试 BK0877，并动态发现名称包含 PCB 的概念板块代码）。
2. 官方指数不可用时，才使用 12 只 PCB 相关上市公司构建等权代理指数，并在数据源字段中明确标记“代理”。
3. 不再把“元件”宽口径行业指数冒充 PCB 指数。
4. 腾讯K线行长度不一致时先统一字段长度，避免 Pandas DataFrame 构造警告。
5. 分钟线超过 4 天未更新则视为过期，不作为当前小时行情。

说明：东方财富 PCB 页面可核对的板块代码为 BK0877；该代码及其接口可用性仍需在 GitHub Actions 实际运行环境中验证。
