# 深南电路每日评分看板

## 指标与权重
- SOX 31.5%
- 纳斯达克100（NDX）13.5%
- 美国10年期收益率环境 18%
- 深南电路自身走势 18%
- AI资本开支人工信号 9%
- 深南电路主力资金流 10%

新增资金流数据来自 AkShare 调用东方财富个股资金流接口，获取深南电路（002916.SZ）最近约100个交易日的主力净流入金额和净占比。金额以亿元显示。资金流评分使用主力净流入占比映射：-5%及以下为0分，0%为50分，+5%及以上为100分。

注意：平台的“主力资金”是按成交单分类估算，并不等于真实机构账户；资金流口径会因数据平台而异。行情及资金流接口可能延迟、变更或临时不可用。数据不足时综合评分按可用指标重新归一化，并显示覆盖率。模型评分不是上涨概率或买卖指令。

## 部署
Streamlit Community Cloud 中选择仓库、`main` 分支、`app.py` 主文件。

## 自动更新
GitHub Actions 工作日 UTC 09:30（台湾/中国时间约17:30）运行 `update_data.py`，更新 `data/history.csv`。GitHub Actions 定时任务可能延迟。进入仓库 Actions 页面可以手动运行工作流。

## AI资本开支信号
`data/ai_signal.txt` 中的值范围为 -2 到 +2，默认0（中性）。修改该文件并提交后，后续更新会使用新信号。
