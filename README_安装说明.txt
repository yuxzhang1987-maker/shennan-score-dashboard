深南电路智能评分看板｜整合升级包
================================

这是基于你上传的 GitHub 项目 ZIP 整合的完整项目快照，不是零散补丁。

本包包含：
1. 原有深南电路综合评分、近期/中期走势、PCB近期/中期走势、大资金流、阈值提醒。
2. 美股科技环境组合评分：SOX 40%、纳斯达克100 25%、英伟达15%、AMD 10%、博通10%。
   美股组合在原综合评分中的总权重仍为15%；如果部分美股数据缺失，会按可用权重计算，
   同时降低数据覆盖率，不会把缺失数据伪装成0分。
3. 独立六因子量化页面：价格动量20%、PCB相对强弱20%、成交量价格配合15%、
   资金流15%、波动风险15%、基本面人工代理15%。不改变原综合评分。
4. 量化因子历史文件 data/quant_factor_history.csv 会在更新任务中自动生成/更新。
5. 工作流按北京时间工作日09:05、10:05、11:05、12:05、13:05、14:05、15:05安排运行。
   GitHub cron不识别中国法定节假日，节假日仍可能启动任务；数据源无新行情时不代表产生了新交易日数据。

重要说明：
- 本包里的 data/ 是你上传时的历史数据快照，不能用它覆盖 GitHub 云端更新得更晚的数据。
- SOX数据源尝试新浪AKShare接口；该接口的可用指数代码可能变化。如果SOX无法获取，
  页面会显示暂无并降低美股组合覆盖率，不会伪造评分。美股个股使用AKShare新浪历史行情接口。
- 目前无法在本地离线环境验证真实行情网站是否可访问；已做Python语法检查和模拟数据测试。
- 基本面因子仍使用 data/ai_signal.txt 人工信号，不是自动财报分析。文件为空/无效时该因子缺失。
- 量化回测受当前数据源历史长度限制；未来5/20/60日收益只用于事后统计，不参与同日评分。
- 资金流数据取决于AKShare/东方财富接口，可能延迟或暂时不可用。
- 这套评分是研究参考，不是收益承诺、上涨概率或自动买卖建议。

安装前请先备份：
1. 打开 GitHub 仓库页面。
2. 点击 Code -> Download ZIP，保存一份云端最新备份。
3. 解压本升级包到电脑新文件夹。

上传到GitHub（重点：只上传代码，不覆盖云端历史数据）：
建议使用GitHub网页逐个替换文件：
1. 替换 app.py
2. 替换 update_data.py
3. 新增 quant_factor_model.py
4. 核对 requirements.txt（本包未新增第三方依赖）
5. 替换 .github/workflows/daily_update.yml
6. 不要上传本包的 data/ 文件夹，不要覆盖 GitHub 上的 history.csv、hourly_history.csv、
   alert_state.json、ai_signal.txt 等云端数据。
7. 如果仓库里仍有旧的 apply_quant_upgrade.py，不需要再运行它；新版本已经直接整合页面。

GitHub网页替换单个文件的方法：
1. 在仓库文件列表中点击要替换的文件，例如 app.py。
2. 点击右上方铅笔图标 Edit this file。
3. 不建议在网页里手工粘贴整份长代码。更稳妥的做法是打开文件页面，
   使用 Add file -> Upload files 上传本包中对应文件；若提示同名文件，按GitHub页面提示提交替换。
4. 对 .github/workflows/daily_update.yml，先进入 .github 文件夹，再进入 workflows 文件夹。
5. 所有文件上传完成后，在 Actions 页面手动运行 Daily Shennan Score Update 一次。
6. 检查运行日志是否有 QUANT_FACTOR 行，以及是否出现美股接口错误；若SOX不可用，日志会提示覆盖率/异常。

特别提醒：
- 上传本包不是删除或重建仓库，不要选择删除仓库。
- 本包保留了你上传时的 history.csv 与 hourly_history.csv 快照，但云端数据可能更新得更晚。
- GitHub Actions cron的运行时间是UTC 01:05至07:05，对应北京时间09:05至15:05。

【新增：智能做T模块 V1.0】
本次新增 intraday_t_model.py，并在 Streamlit 页面底部增加“深南电路智能做T系统”。
- 策略：震荡回归 + 趋势跟随，稳健过滤；没有信号时显示观望。
- 行情：独立获取东方财富5分钟K线，保存到 data/t_intraday_5m.csv；信号记录保存到 data/t_signal_history.csv。
- GitHub Actions：每个工作日原有小时更新后，额外尝试更新5分钟行情历史；数据源失败不会中断原评分流程。
- 回测：提供“先卖后买回”同日差价测试和T+1方向性测试，并明确显示样本数与限制。历史行情接口返回范围有限，需随自动更新持续积累；样本不足时不要投入实盘。
- A股T+1：当天新买入股份不能当天卖出。卖出信号仅适用于已有可卖底仓；同日卖出后买回使用的是原有可卖股份。
- 机动资金默认5万元，可在页面调整到1万至10万元。建议先模拟至少20–30个交易日，模型不自动下单。

更新方式：下载并解压本ZIP，将其中项目文件覆盖GitHub仓库同名文件；保留 data/history.csv、data/hourly_history.csv、data/alert_state.json 等原有历史数据。新增的 data/t_intraday_5m.csv 会在首次成功获取5分钟行情后自动创建。随后到 GitHub Actions 手动运行 Daily Shennan Score Update，等待完成后刷新 Streamlit 页面。
